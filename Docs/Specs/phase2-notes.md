### Decisions made in this slice

- **Needs a Look stays in the Filter list.** The brief's and 04's kinds are Course, Cooked, Favorites, Collection, Cookbook and Tag; Needs a Look was a Filter entry since row 9 and `RecipeFilter` keeps it, so it is a switch beside Favorites rather than a filter that could be set (and shown as a token) with no row to unset it.
- **Tokens follow the rule literally.** "Kind: selection" for every list kind, so Cooked reads "Cooked: Never Cooked" and "Cooked: Cooked"; the switches read their name alone. The second reads oddly (row 46).
- **One value for Collection, Cookbook and Tag.** `RecipeFilter` holds one of each and the brief keeps the model, so "several allowed where the kind allows it" means Course only; a second tap on the chosen value clears it. Unset kinds read "Any".
- **One presentation for both widths.** `.popover` on the Filter button is the iPad popover and adapts to a sheet in compact width, so the menu bar's Filter… and the toolbar open the same thing, anchored to the button on iPad.
- **Add (+) on Cookbooks is a one-item menu**, naming the way in as the Recipes Add does; Scan Sources Page joins it in slice 7 (row 51 asks whether a plain button is better until then).
- **The subtitle is split off.** Open Library often folds it into the title ("The Food Lab: Better Home Cooking Through Science"); the first ": " splits it, the card shows the subtitle, and the shelf keeps the short title (`Book` has no subtitle field).
- **A search result's ISBN is its best-matching edition's** (`editions.isbn`, ISBN-13 first), and its year is the work's first publication year; the work's own `isbn` list mixes every edition, foreign ones first.
- **Details by hand replace the lookup in place** rather than pushing, so Cancel stays in the corner; they start from what was typed.
- **A book already on the shelf by ISBN opens instead of a duplicate** ("On Shelf").
- **Covers**: the Open Library "L" image, kept only if it is at least 1 KB, re-encoded to the 900 px, 0.8 JPEG of a recipe's cover copy; Edit Book Info takes a Photos image the same way.
- **The punchlist lists render when entries exist** (read-only; "Scan now" waits for slice 5), so the control does something the day slice 5 fills it.
- **The scanner checks the description first**, then `DataScannerViewController.isSupported` and `isAvailable`, so nothing touches the camera without one. Caleb added the description during the slice (`c2c96b3`); the simulator still hides the button (it can't scan).
- **Google Books' key** would come from `GoogleBooksAPIKey` in the Info dictionary; a custom key needs an Info.plist entry or build setting, Caleb's to add.
- **Escape stays `.keyboardShortcut(.cancelAction)`.** A UIKit first-responder view answering Escape was tried and dropped: ⌘K on the same toolbar button closed the sheet, so sheets' shortcuts are reachable, and the simulator never delivered Escape to anything (below).
- **Commit trailer.** `Co-Authored-By: Claude Opus 5.5`, the model that did the work.

### Not verified, and findings

- **Escape itself.** With hardware key events from an XCTest runner (slice 10's, copied into the scratchpad), Escape never reached the app's key commands on the iOS 27 simulator: not a sheet's `.cancelAction` button, not a hidden content button, not a main-menu command with Escape tried for the purpose, and not `pressesBegan` on a view that was first responder, where "a" arrived; it only closed an open UIKit menu. ⌘I and ⌘F arrived as before, and ⌘K given to Add Cookbook's toolbar Cancel for the test closed the sheet, so the sheets' shortcuts are reachable and `.cancelAction` should answer a real Escape. Escape on the three sheets is left for a device with a keyboard (Caleb). Row 43's original report may have been the same harness, though the shortcuts were indeed missing then.
- **The menu bar's View → Filter…**: by inspection only; the headless simulator shows no menu bar (slice 10).
- **The ISBN scanner**: written, hidden on the simulator (no camera; `isSupported` false) although the description now exists; on a device it should show beside the ISBN field. Unverified until a device build; slice 4 owns the camera.
- **The first live lookup on the iPhone** answered "Open Library didn't answer as expected" before the failure log existed; every later lookup (five, on both devices) worked, and nothing was logged since. Possibly Open Library's own hiccup; the "books" log will say next time.
- **Title search isn't limited to cookbooks**: "Plenty" put Enid Blyton's "Five Have Plenty of Fun" first (row 47).
- **ISBN-10s ending in X can't be typed** on the number pad, iPhone or iPad (row 48); every barcode since 2007 carries the ISBN-13, which works.
- **No screen assigns a recipe to a cookbook** (row 49); the checks linked recipes with a store edit.
- **iPad Book detail spans the whole column** (the segmented control is about 1,050 pt wide) (row 50).
- **Open Library data**: Jerusalem's edition names Ottolenghi alone (Sami Tamimi is on the cover); Edit Book Info fixes a book.
- **Disabled buttons in a form** draw their title in the label color with a tinted icon on iOS 27 (Look Up ISBN before an ISBN is typed), so they read as enabled until tapped; the system's drawing, not changed.
- **Not exercised**: the shelf's completeness bar and the punchlist lists with entries (none exist until slice 5), Edit Book Info's cover change and removal saved, details by hand saved, the offline and not-found messages on screen (covered by tests), dark mode, VoiceOver, portrait and a compact iPad window.
- **Planning docs** (read-only here): phase2-plan's Slice 1 lists Export list in Book detail's More, which the brief defers to its slice; 04 §5.1 "Recipes filters" still carries the sentence about the menu closing after each choice, now moot.
- **Typing on the simulators** dropped or doubled characters when sent quickly; values were typed in short pieces and checked.
- **Simulator state.** iPhone: The Food Lab on the shelf (added by ISBN, kept as test data); Salt, Fat, Acid, Heat deleted; 11 recipes, none linked to a book; collections Sunday Suppers Club and Project Cooking as before; shelf sort back to Title. iPad: Jerusalem on the shelf (kept); Plenty More deleted; 11 recipes, none linked; no collections. Both run this build, launched on the Recipes grid; the key-event runner is uninstalled.
