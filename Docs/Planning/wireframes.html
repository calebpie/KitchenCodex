Recipe Codex Wireframes

Core screens and flows for iPhone 17 Pro (402 × 874 pt) and the 13-inch iPad Pro (1376 × 1032 pt, landscape), drawn against the Human Interface Guidelines as updated through October 2026. Gray blocks stand for photos. Frosted pills are Liquid Glass: they appear only in the navigation layer, never inside content. Numbered dots are explained under each frame.

iPhone

Five tabs in the order the work happens: Recipes, Pantry, Plan, Cook, and a trailing Search tab, as the HIG now recommends. Books is a view switch inside Recipes. Pantry holds ingredients, tools, sources, cellar and bar, kitchens and your profile; the top toolbar is contextual (Add and a More menu) with no profile button. Revised Oct 17 after review; a Pantry frame is not drawn yet.

Live Activity

One Live Activity per session, starting with the iPhone design and adapting to the Lock Screen, StandBy, the Apple Watch Smart Stack and the Mac menu bar. Text is medium weight or heavier, content hugs the camera cutout, and the limited-width variant is the soonest timer alone.

iPad

The same five tabs in a top tab bar that converts to a sidebar. Recipes and Books use three-column split views; Plan uses two. Cook and service mode can open in their own window on a stand. Scroll sideways to see all frames.

Flow maps

Add a whole cookbook

Books · Add→Scan ISBN→Confirm book card→Scan contents / index→Extract punchlist (on-device model)→Correct list→Scanning session→Background OCR + structuring→Review queue→Book shows completeness

Plan and run an event

Plan · New event→Guests, times, kitchen→Menu slots + candidates→Ask Codex (optional)→Balance + warnings→Finalize→Shopping list by stop→Workback schedule→Daily prep on Cook→Service mode→Debrief

Dashed boxes are model-assisted steps; each has a rules-only fallback and an edit step after it.
